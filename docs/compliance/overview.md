# Compliance para Sistemas de IA

O Guimí Test AI cobre os principais frameworks regulatórios que afetam sistemas de IA em produção no Brasil e no mundo.

## Frameworks suportados

| Framework | Jurisdição | Foco | Status |
|-----------|-----------|------|--------|
| [**LGPD**](lgpd.md) | Brasil | Proteção de dados pessoais em IA | ✅ Disponível |
| [**EU AI Act**](eu-ai-act.md) | União Europeia | Sistemas de IA de alto risco | ✅ Disponível |
| [**OWASP LLM Top 10**](owasp.md) | Global | Segurança de aplicações LLM | ✅ Disponível |
| [**NIST AI RMF**](nist.md) | EUA / Global | Gestão de riscos de IA | ✅ Disponível |
| **ISO/IEC 42001** | Global | Gestão de sistemas de IA | 🔜 Em breve |
| **CCPA** | Califórnia, EUA | Privacidade do consumidor | 🔜 Em breve |

## Por onde começar

Se você opera no Brasil, comece pela [LGPD](lgpd.md) — é a regulamentação com maior risco imediato de multas e a que tem interpretações mais específicas para IA.

Se você exporta serviços para a Europa ou atende usuários europeus, adicione o [EU AI Act](eu-ai-act.md) — em vigor desde agosto de 2024, com obrigações progressivas até 2027.

Para segurança técnica independente de jurisdição, o [OWASP LLM Top 10](owasp.md) é o ponto de partida universal.
